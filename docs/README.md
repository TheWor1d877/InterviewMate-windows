# InterviewMate

运行在 Windows Terminal 里的面试辅助程序。采集语音、截图和手动输入的题目，交给 DeepSeek 生成可以直接说出口的回答或 C++ 算法代码，结果在终端左右两栏流式显示。项目相关题目先经 Dify 检索项目资料。

目标、边界和设计原则见《1-总纲》。

本项目为 Windows-only 实现：截图走 `mss`，系统回环音频走 WASAPI，全局热键由 AutoHotkey v2 绑定，进程通信走 TCP loopback 加 token，进程探测与回收走 `psutil`。

## 开发顺序

按 2 到 8 的顺序做，每个阶段结束时能跑起来验证。

```text
2 骨架与配置
   |
3 文本输入与流式回答          ← 这一步做完就有能用的最小闭环
   |
   +-- 4 截图输入与多模态
   |
   +-- 5 语音输入与流式 ASR
   |
   +-- 6 Dify 检索与项目知识
   |
   +-- 7 代码问题模式
   |
8 集成与验收
```

4、5、6、7 之间没有依赖，先后顺序按手感定。

## 已知取舍

| 取舍 | 结论 |
|---|---|
| 生成走哪个服务 | DeepSeek 直连，Dify 只做检索 |
| 问题分类 | 关键词规则，不调模型 |
| 题型与检索需求 | 两个独立字段 |
| 截图 | 读进内存直接发送，不落盘 |
| 生成代码 | 不编译验证 |
| 截图目标 | 整屏、主屏或指定屏，不做窗口与区域 |
| 布局 | 两种题型共用两栏 |
| 音频回调 | 只入队，不发网络请求 |
| 重试 | 只在首个输出之前 |
| 检索分数阈值 | 默认关闭，用真实样本校准 |
| Dify 故障 | 降级继续，不阻断 |
| 全局快捷键 | F8、F9 由 AutoHotkey v2 绑定，终端失焦也可用；终端有焦点时由应用内按键处理 |
| 语音来源 | 靠标签区分，不做说话人识别 |
| 语音文本 | 多次解码结果合并 |
